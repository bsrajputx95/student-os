## Current interface and practice update

The student and staff interface now uses a stronger violet/blue palette, clearer text/control contrast, more visible selected tabs, colored progress indicators and a new SVG favicon. Practice includes a saved role/level/skill-gap lens across 15 career roles; role-specific scenarios, relevant problem metadata, quizzes, labs, courses and company guides; and a direct AI interview tab. The lens does not reset the main journey or award mastery. Fifteen original role checks add 45 questions. Sixty-one real company logos and 128 illustrated profile portraits are stored locally and attributed in [BRAND_ASSETS.md](BRAND_ASSETS.md).

Quid rebuilds current academic context on the server for each question. Students receive their own records. Authorized faculty can name or select a student, inspect a grounded summary, follow a roster link and open Quid directly from a student profile. Ambiguous names require a choice; explicit cross-college selections are rejected. Context includes scored work, assignments/feedback, projects, preparation, career records and permitted mentor notes; private DMs and credentials are excluded. College context includes cohort skills/coursework and query-relevant student records. Saved-record summaries are available without a provider. Native Gemini supports server-only credentials, system instructions and JSON review output; its transport and ordered failover are tested with stubs. A live Gemini 3 Flash response has been verified against the local roster using server-calculated cohorts; the private key is stored only in ignored local configuration.

This batch’s focused tests cover all 15 resource mappings and interview prompts, role preference isolation, academic-context privacy/freshness/college scope, scoped conversation history and native Gemini transport. Built-site mobile/desktop checks cover the new Practice controls/interview and logo rendering, with no horizontal overflow or console warnings/errors in the reviewed views. These remain smoke checks, not a comprehensive accessibility or device certification.

## Quid academic analysis and subject artwork

Faculty questions now use a typed, server-owned academic query: skill, year, score comparison, department, track, company, coursework, course completion and activity filters. Exact matching counts and named results are calculated from the authorized campus roster, with searchable results, support drill-down and CSV export. Unassessed skills are excluded from skill rankings. Historical sample scores are distinguished from verified evidence. A cohort question clears a stale selected-student context; an explicitly named student takes precedence over the picker. Student support suggestions include relevant preparation gaps, recorded lower-scored attempts, actual learning resources, backlog review and a seven-day follow-up. No guidance is automatically published.

Gemini 3 Flash (`gemini-3-flash-preview`) returned a live answer after the requested 3.8 Flash model returned high-demand errors and higher Pro/Argon models returned quota errors. Model availability is provider-controlled. Optional configured fallback models are tried only on transient/unavailable/rate-limit failures; authentication failures are not retried. When all models fail, Quid still returns the exact academic report with a provider-unavailable notice. Memory-database HTTP tests do not load the checkout’s live `.env`. Credentials remain server-only and ignored by Git.

Twelve original SVG subject scenes replace repeated course glyphs and generic code-window thumbnails throughout learning cards and previews. Six additional locally served provider marks bring the brand asset set to 67. Course cards have distinct colors, restrained hover depth and reduced-motion support.
